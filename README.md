# 💣 Detonatrix

**Detonatrix** é um jogo de ação e estratégia 2D inspirado no clássico estilo arcade de arena e labirintos, desenvolvido em **C** utilizando a biblioteca **Raylib**. 

Em um ambiente dinâmico e acelerado, o jogador deve posicionar esferas energéticas, destruir blocos pelo mapa, coletar melhorias (*power-ups*) e derrotar oponentes antes que o tempo acabe.

---

## 🎮 Funcionalidades

- **Mecânica Clássica e Fluida:** Movimentação em grade com colisões precisas.
- **Blocos Destrutíveis:** Limpe o mapa para abrir caminhos e revelar melhorias secretas.
- **Sistema de Power-ups:**
  - 💥 **Alcance Aumentado:** Expande a área de explosão.
  - ⚡ **Velocidade:** Aumenta a velocidade de movimento do personagem.
  - 💣 **Bomba Extra:** Permite posicionar mais de uma esfera energética ao mesmo tempo.
- **Gráficos em Pixel Art:** Interface limpa e retrô construída sob medida na Raylib.
- **Efeitos de Áudio:** Efeitos sonoros imersivos para explosões, passos e itens.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** C (C99)
- **Biblioteca Gráfica:** [Raylib](https://www.raylib.com/)
- **Build System:** CMake / Make

---

## 🚀 Como Executar o Projeto

### Pré-requisitos

Certifique-se de ter um compilador C instalado (como `gcc` ou `clang`) e a biblioteca **Raylib** configurada no seu ambiente.
